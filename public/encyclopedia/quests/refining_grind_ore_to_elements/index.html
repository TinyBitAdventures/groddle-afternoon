Perfectly Refined

Quest

In the remake

How to get this quest

  • Offered when you learn Refining I.
  • Refining I, learn it

Steps

Each step in Tiny Speck’s words, with what it needs.

  1. Refine 50 Red Elements

    • ×50 Red Element

  2. Refine 50 Green Elements

    • ×50 Green Element

  3. Refine 50 Blue Elements

    • ×50 Blue Element

  4. Refine 50 Shiny Elements

    • ×50 Shiny Element

Where to go

  • Nothing to hand in: when the last step is done, your Magic Rock comes to you with the end of the quest, wherever you are.

Rewards

300 iMG, 200 currants, 150 energy, 30 favor with Zille

Linked to this quest

Comes next

  • Refining II, you can learn it after

Things it involves

  • Red Element
  • Green Element
  • Blue Element
  • Shiny Element
  • Grinder
  • Elemental Pouch

In Tiny Speck’s words

The quest

Obtain 50 of each Element by grinding down some ore chunks. You'll need a Grinder (available from any Street Spirit who sells Hardware or Alchemical Goods) and an Elemental Pouch (but you probably already have one of those).

When it is offered

Congratulations on learning the refining skill. Now let's put it to use: break down enough ore chunks to get 50 of each of the four Elements.

When you finish

Well done! Grind lots of ore so you have the Elements to get ahead with Alchemy.

From Tiny Speck’s game code.

In the remake

You can do this quest in the remake.
