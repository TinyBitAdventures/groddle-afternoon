Fuelmaker Core

Plural: Fuelmaker Cores

In the remake

1,250 currants, sells for 825

In Tiny Speck’s game

Install the Fuelmaker core and the final piece of the puzzle will be in place. Now you just need fuel to fuel the Fuelmaker.

  • You need the Engineering skill to assemble machines.
  • You can use this to assemble a Fuelmaker.
  • This can be purchased from a Hardware Vendor or a Tool Vendor.
