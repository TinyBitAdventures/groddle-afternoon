Machine Engine

Plural: Machine Engines

In the remake

2,500 currants, sells for 1,650

In Tiny Speck’s game

Install this engine, and your machine is one step closer to purring like the quintessential classic, thrumming like the deeply resonant inner chambers of Zille's enormous throat.

  • You need the Engineering skill to assemble machines.
  • You can use this to assemble a Blockmaker, a Fuelmaker, a Metal Machine or a Woodworker.
  • This can be purchased from a Hardware Vendor or a Tool Vendor.
