Tree Poison Antidote

Plural: Tree Poison Antidotes

In the remake

375 currants, sells for 248

In Tiny Speck’s game

Tree antidote: the only known reprieve for the mostly dead tree (there's a big difference between "mostly dead" and "all dead"). Contains five sips at the last chance saloon for five lucky trees.

  • This can be made with a Cauldron.
  • You need to learn Potionmaking I to use a Cauldron.
