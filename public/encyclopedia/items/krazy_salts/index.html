Krazy Salts

 

In the remake

111 currants, sells for 73, stacks to 33

In Tiny Speck’s game

A vital magical ingredient, Krazy Salts should never be mistaken for normal, run of the spice-mill Pinch of Salt. For one thing, you need to save it for Potions. For the other, this Salt be KRAZY! Seriously: keep it away from sharp objects.

  • This can be made with a Beaker.
  • You need to learn Intermediate Admixing to use a Beaker.
