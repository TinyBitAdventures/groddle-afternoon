Awesome Pot

Plural: Awesome Pots

In the remake

300 currants

In Tiny Speck’s game

An awesome pot is used to make special dishes. Very special.

  • You need the skill Master Chef I to use this.
  • Additional recipes will become available if you use the Awesome Pot more.
  • This can be made with a Tinkertool or purchased from a Kitchen Tools Vendor.
  • You need to learn Tinkering I to use a Tinkertool.
  • The recipe for this will become available after you learn Tinkering V.
