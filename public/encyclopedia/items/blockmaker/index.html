Blockmaker

Plural: Blockmakers

In the remake

In Tiny Speck’s game

Even simple building blocks have to come from somewhere... and this is where. Learn to harness the power of this machine and Urth Blocks of superiour blockiness shall be yours.

  • You need the skill Blockmaking to use this.
  • You'll need a Machine Stand, Blockmaker Chassis, Machine Engine and Blockmaker Plates to assemble a Blockmaker.

Quest timers

  • Machine Shop Pit Stop: Fully Assemble and Disassemble a Machine in 2 minutes. The countdown for the quest “Machine Shop Pit Stop”, shown with this item’s picture: if it runs out first, the quest fails.
