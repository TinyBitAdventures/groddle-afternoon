Metal Machine

Plural: Metal Machines

In the remake

In Tiny Speck’s game

A bangy, squeaky, marvellous red-hot metal machine. For the mutation of Plain Metal, Tin, Copper and Molybdenum into Metal Rods, Bars and Girders. None more metal.

  • You need the skill Metalworking to use this.
  • You'll need a Machine Stand, Metal Machine Mechanism, Metal Machine Tooler and Machine Engine to assemble a Metalmaker.
