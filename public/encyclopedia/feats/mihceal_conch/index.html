Mihceal, Blow that Conch

Feat

Not yet

In Tiny Speck’s game

A Feat was a goal the whole world worked toward together, for one day. Each time you added to it, the game told you so:

Your conch-playing has been counted as a contribution towards recreating the Feat "Mihceal, Blow that Conch". There are so many plays left to be done in order to complete the feat.

From Tiny Speck’s game code. The goals did not survive: the remake sets its own.
