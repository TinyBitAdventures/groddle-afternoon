Botany

Growing skill

In the remake

In Tiny Speck’s game

Learn time 12 min, Growing

The Botanist has certain knowledge of the mystical life-giving and life-granting interactions between a bean and its seasoning. Botany confers the ability to operate a Bean Seasoner, and do it "just so", allowing the production of all manner of plantable beans.

When you learn it

Your mad Botany skills confer upon you the ability to use a Bean Seasoner and Spices to season up all manner of plantable Beans. Go plant a patch or three.

Giants

Spriggan (primary), Humbaba, Mab

From Tiny Speck’s game code. The learn time is how long it takes in the remake, before Better Learning.

What it needs

  • Arborology II, learn it first
  • Intermediate Admixing, learn it first

What it opens

Quests

  • Advanced Bean Fancification, offered when you learn it
  • Mendel's Apprentice, offered when you learn it

Things you can make with it

  • Egg Plant Bean, you can make it
  • Bean Tree Bean, you can make it
  • Bubble Tree Bean, you can make it
  • Fruit Tree Bean, you can make it
  • Spice Plant Bean, you can make it
  • Gas Plant Bean, you can make it
  • Wood Tree Bean, you can make it
  • Tree Poison, you can make it

In the remake

You can learn this skill in the remake.
