Saucery II

Cooking skill

In the remake

In Tiny Speck’s game

Learn time 24 min, Cooking

Upgrading to Saucery II will unlock several new recipes for your trusty Saucepan whilst making your use of the tool more efficient at the very same time.

When you learn it

You did it: Saucery II. Like some sort of crazy culinary rocket, you grow faster while your skills grow nummier. Remember: The more recipes you try with your Saucepan, the more imagination you gain. And with this imagination comes even more recipes. It's an endless cycle. An endless tasty cycle.

Giants

Pot (primary), Grendaline, Spriggan

From Tiny Speck’s game code. The learn time is how long it takes in the remake, before Better Learning.

What it needs

  • Saucery I, learn it first
  • Rolling Boiler, earn it first

What it opens

Quests

  • Get Sauced, offered when you learn it

Things you can make with it

  • Creamy Catsup, you can make it
  • Wicked Bolognese Sauce, you can make it
  • Tangy Sauce, you can make it

In the remake

You can learn this skill in the remake.
