Mining I

Industrial skill

In the remake

In Tiny Speck’s game

Learn time 4 min, Level 3 or more, Industrial

Mining is the gateway to some pretty valuable resource extraction procedures: you'll be using a Pick to produce Chunks of Ore from special rocks scattered around the world. Though mining is hard work, the rewards are worth it.

When you learn it

Welcome to gritty but rewarding field of Mining! Some think of mining as an aggressive act, but most Rocks really dig it. Now that you've got some basic skills, grab a Pick, get out there, and show those Rocks some tough love.

Giants

Zille (primary), Alph, Cosma

From Tiny Speck’s game code. The learn time is how long it takes in the remake, before Better Learning.

How long it takes

How long one go takes at each rank, and the energy and tool wear it costs. The numbers are Tiny Speck’s game data, which the remake reads too. Where a note says so, the remake runs the time faster than Glitch did. With speed cards, only the best one you own counts.
