Refining I

Industrial skill

In the remake

In Tiny Speck’s game

Learn time 12 min, Industrial

Refining is the logical next step after mining: take all those chunks of ore and grind them all the way down to elementary particles. Those elements will come in handy. (You'll need a Grinder.)

When you learn it

Hey there, Refiner 49er. So you've committed to the dusty yet gratifying field of Refining, have you? First step: get yourself a Grinder and start, you know, grinding some ore.

Giants

Zille (primary), Alph, Tii

From Tiny Speck’s game code. The learn time is how long it takes in the remake, before Better Learning.

What it needs

  • Element Handling, learn it first
  • Mining I, learn it first
  • Get Elemental!, finish it first

What it opens

Skills

  • Refining II
  • Smelting

Quests

  • Perfectly Refined, offered when you learn it
  • Well, I Neva!, offered when you learn it

Things you can make with it

  • Red Element, you can make it
  • Green Element, you can make it
  • Blue Element, you can make it
  • Shiny Element, you can make it

In the remake

You can learn this skill in the remake.
