Teleportation I

Intellectual skill

In the remake

In Tiny Speck’s game

Learn time 12 min, Intellectual

With the first Teleportation skill, you will be able to set a landing point (almost) anywhere in the world and then teleport back to it from (almost) anywhere else. Warning: teleporting is pretty draining, energy wise.

When you learn it

So, it's Teleporting you want to do, hm? The first step is figuring out where you want to go to. Go there. Establish your landing point. Then go back to your first location. Then teleport back to your landing point. What? Nobody said this was going to be easy.

Giants

Lem (primary), Alph, Cosma

From Tiny Speck’s game code. The learn time is how long it takes in the remake, before Better Learning.

What it needs

  • Meditative Arts I, learn it first

What it opens

Skills

  • Teleportation II

Quests

  • To Xalanga, And Beyond, offered when you learn it

In the remake

You can learn this skill in the remake.
