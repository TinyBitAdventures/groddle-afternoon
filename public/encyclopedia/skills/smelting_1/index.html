Smelting

Industrial skill

In the remake

In Tiny Speck’s game

Learn time 24 min, Level 2 or more, Industrial

With Smelting, you can use an industrial-strength Smelter to extract Plain Metal from the Chunks of Metal Rocks. This is much preferable to using your bare hands.

When you learn it

Well done, apprentice Smelterer. With this skill, you can use a Smelter to extract Plain Metal from the Chunks of Metal Rocks. It also lets you say "smelter" a lot, which is a surprisingly pleasing thing to do.

Giants

Zille (primary), Alph, Tii

From Tiny Speck’s game code. The learn time is how long it takes in the remake, before Better Learning.

What it needs

  • Refining I, learn it first

What it opens

Skills

  • Alchemy II

Quests

  • Helter Smelter, offered when you learn it

Things you can make with it

  • Plain Metal Ingot, you can make it

In the remake

You can learn this skill in the remake.
