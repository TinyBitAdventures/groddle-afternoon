Cocktail Crafting II

Cooking skill

In the remake

In Tiny Speck’s game

Learn time 30 min, Cooking

Advanced drinks have some very special qualities, imbuing the imbiber with highly desirable magic. Advancing to the second level of Cocktail Crafting grants you some new recipes which will make you pretty desirable yourself.

When you learn it

Welcome to a brand-new level of Cocktail Crafting. What's new at this level, you wisely ask yourself? How about the ability to make special drinks with special qualities? Yes, we thought you'd like that.

Giants

Friendly (primary), Grendaline, Pot

From Tiny Speck’s game code. The learn time is how long it takes in the remake, before Better Learning.

What it needs

  • Cocktail Crafting I, learn it first
  • Mediocre Mixologist, earn it first
  • Spent First Emblem of Friendly, earn it first

What it opens

Quests

  • Bartending with Yourself... Oh Oh Oh, Bartending with Yourself, offered when you learn it

Things you can make with it

  • Cosma-politan, you can make it
  • Flaming Humbaba, you can make it
  • Pungent Sunrise, you can make it
  • Face Smelter, you can make it

In the remake

You can learn this skill in the remake.
