Crystallography

Alchemy skill

In the remake

In Tiny Speck’s game

Learn time 24 min, Alchemy

Any alchemist with a Crystalmalizing Chamber can create Plain Crystals, but learn Crystallography and you'll save your chamber from some of the usual chafe. The Giants sometimes favor those with this skill.

When you learn it

Congratulations, you are now an official Crystallographer! Or, is it Crystalmalizer? Crystalogist? Well, whatever … all you need is a Crystalmalizing Chamber, and you can make crystals!

Giants

Tii (primary), Cosma, Zille

From Tiny Speck’s game code. The learn time is how long it takes in the remake, before Better Learning.

What it needs

  • Alchemy I, learn it first

In the remake

You can learn this skill in the remake.
