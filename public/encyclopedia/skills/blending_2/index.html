Blending II

Cooking skill

In the remake

In Tiny Speck’s game

Learn time 12 min, Cooking

Taking Blending to the next level not only teaches you a handy parcel of otherwise unlearnable recipes, it makes operating a Blender much less taxing.

When you learn it

Now that you've taken Blending to the next level, you could almost refer to yourself as a trans-blendologist with a straight face. Almost. Or you could simply explore strange new recipes with an ease you once could only dream of.

Giants

Friendly (primary), Grendaline, Pot

From Tiny Speck’s game code. The learn time is how long it takes in the remake, before Better Learning.

What it needs

  • Blending I, learn it first
  • Pulse, Frappe, Mix & Blend, earn it first

What it opens

Quests

  • Get into a Froth, offered when you learn it

Things you can make with it

  • Too-Berry Shake, you can make it
  • Earthshaker, you can make it
  • Bubble Tea, you can make it
  • Red Sno Cone, you can make it
  • Purple Sno Cone, you can make it
  • Rainbo Sno Cone, you can make it

In the remake

You can learn this skill in the remake.
