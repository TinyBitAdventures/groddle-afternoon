Animal Husbandry

Animals skill

In the remake

In Tiny Speck’s game

Learn time 24 minAnimals

Only the imagination of a Giant can create a new life. But, also, you can too: Animal Husbandry allows the use of an Egg Seasoner to create seasoned eggs and unlocks the Incubate command on chickens which will get those eggs hatched. Voila: you have a brand new baby animal.

When you learn it

You have embarked on the noble and exciting field of Animal Husbandering. But everyone knows you can't husband an animal without some Eggs and an Egg Seasoner. Those, plus your newly discovered ability to use the Incubate command on Chickens, are all you need to create fubsy new life.
