Master Chef II

Cooking skill

In the remake

In Tiny Speck’s game

Learn time 1 h 36 min, Cooking

The second level of Master Chef unlocks additional recipes for the Awesome Pot and increases your efficiency in using it to make lower-level recipes.

When you learn it

With Master Chef II, you're flying mighty close to the big shiny oven in the sky. Make sure it doesn't go to that big head of yours now that you can whip up advanced recipes in a jiffity-split

Giants

Pot (primary), Grendaline, Humbaba

From Tiny Speck’s game code. The learn time is how long it takes in the remake, before Better Learning.

What it needs

  • Master Chef I, learn it first
  • 1-Star Cuisinartist, earn it first
  • Spent First Emblem of Pot, earn it first

What it opens

Things you can make with it

  • Yummy Gruel, you can make it
  • Fortifying Gruel, you can make it
  • Rich Tagine, you can make it
  • Chilly-Busting Chili, you can make it
  • Oaty Cake, you can make it
  • Pad Tii, you can make it
  • Heston Mash, you can make it
  • Luxury Tortellini, you can make it
  • Precious Potato Salad, you can make it
  • Potian's Feast, you can make it

In the remake

You can learn this skill in the remake.
