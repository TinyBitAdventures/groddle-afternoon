Cheffery II

Cooking skill

In the remake

In Tiny Speck’s game

Learn time 12 min, Cooking

Cheffery II takes that friendship with the Frying Pan to a new level, allowing several new recipes and just plain making you more efficient with your tool.

When you learn it

Cheffery II! Twice as exciting as Cheffery I? You bet your last Gameshow Ticket. Now you'll be learning more recipes and becoming more efficient with your Frying Pan as you continue to stroll down a path of yumminary delights.

Giants

Pot (primary), Humbaba, Zille

From Tiny Speck’s game code. The learn time is how long it takes in the remake, before Better Learning.

What it needs

  • Cheffery I, learn it first
  • Decent Hash Slinger, earn it first

What it opens

Skills

  • Cheffery III

Quests

  • Eggy McWeggies, offered when you learn it

Things you can make with it

  • Spicy Quesadilla, you can make it
  • Scrumptious Frittata, you can make it
  • Eggy Scramble, you can make it
  • Mexicali Eggs, you can make it
  • Messy Fry-Up, you can make it
  • Urfu, you can make it
  • Onion Ring, you can make it

In the remake

You can learn this skill in the remake.
