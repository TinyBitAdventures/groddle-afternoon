Potionmaking III

Alchemy skill

In the remake

In Tiny Speck’s game

Learn time 7 h 12 min, Alchemy

The venerable art of Potionmaking III, once lost to the mists of time, has been found to contain knowledge of a particularly potent set of potions: those that give Garden Masters sole dominion over speedy gardening, and one potent enough to please the giants by the power of drinking it alone.

When you learn it

Congratumultiultralations. With Potion Making III, you have gained access to the five most powerful potions known to gardening, and a potion which, when drunk, releases an odour so pleasant that it causes the giants imaginations to tingle simultaneously and release a small shower of favor upon the drinker. Which is a lot less messy than it sounds.

Giants

Tii (primary), Mab, Spriggan

From Tiny Speck’s game code. The learn time is how long it takes in the remake, before Better Learning.

What it needs

  • Potionmaking II, learn it first
  • Epicly Perilous Potian Trial of Perilousness, finish it first

What it opens

Things you can make with it

  • Draught of Giant Amicability, you can make it
  • Soak-All Solution, you can make it
  • Seed-Dibber Libation, you can make it
  • Manyharvest Cordial, you can make it
  • Liquid Super-Hoe, you can make it
  • Dung-Kicker Drops, you can make it

In the remake

You can learn this skill in the remake.
