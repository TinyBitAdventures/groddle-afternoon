Hub map geometry + art preservation
===================================

Geometry (complete offline)
  Source: Tiny Speck GSJS CC0 — inc_data_maps_prod.js
  assets/maps/index.json           — 94 hubs catalog
  assets/maps/hubs/hub-<id>.json   — streets + GO exits (760×460)
  61 hubs have street segments (1,396 total street lines)
  33 hubs are empty/POL/templates (0 streets)

  hub-56-groddle-forest.json is a legacy copy of hubs/hub-56.json

Art preserved offline
  assets/maps/art/thumbs/sm_*.jpg  — 48 hub thumbs (150×91) from world_map.fla
  assets/maps/art/world/*.jpg      — continent world-map bitmaps from same FLA
  thumbLocal on ~57 hub JSON files when a matching thumb exists

Region backgrounds from the thumbs (G471, round 5, 2026-10-31)
  assets/maps/art/bg/<region>.webp (760×460) and <region>@2x.webp (1520×920): each public
  region's thumb from world_map.fla, scaled to the frame and softened into a painting
  (tools/map-backgrounds/build.mjs, provenance in art/bg/backgrounds.json). The thumbs line up
  with the 2012 encyclopedia maps at scale 1 (reference only). js/map-graph.js draws one behind
  the streets when no full painting (bgLocal) exists; test, tower and POL hubs keep the plain map.

CDN hub paintings (full 760×460 bg/fg) — URLs preserved, files NOT on Wayback
  assets/maps/art-urls.txt         — 89 original c1/c2.glitch.bz URLs
  Each hub JSON keeps bg / fg CDN strings; bgLocal/fgLocal fill when recovered
  Re-try: ~/Documents/glitch-audit/scripts/recover-map-art.py

In-game
  Map (G) opens player hub; dropdown browses all hubs with geometry
  GO buttons switch hub map view (explore); yellow paths = playable streets only

Streets left off the map (round 5, 2026-10-31)
  invisible_to_outsiders on a hub street: the Start streets, apartment towers and basements,
  machine rooms and Muufo's forgotten floor, which the client drew only for a player standing
  on them (MapHub.as drawStreet). Written by tools/build-map-hidden.mjs from GSJS
  (greeting_locations, machine_rooms, the Apt basements rule) and the Tribute Blog's Nov 2012
  region maps (reference only). The region list offers GSJS public_hubs only (js/map-graph.js).
