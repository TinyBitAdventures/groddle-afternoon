Woodworker

Plural: Woodworkers

In the remake

In Tiny Speck’s game

How much wood would a Woodworker work if a Woodworker could work wood, you say? Glad you asked. It's four. Four Planks make a Board, four Boards a Post, four posts make a Beam. So how much wood would a Woodworker work if one could work wood? Four.

  • You need the skill Woodworking to use this.
  • You'll need a Machine Stand, Woodworker Fuser, Woodworker Chassis and Machine Engine to assemble a Woodworker.
