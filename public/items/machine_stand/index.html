Machine Stand

Plural: Machine Stands

In the remake

In Tiny Speck’s game

This generic machine stand provides just the right foundation upon which many a machine can be built. As with all good foundations, once assembled it cannot be moved.

  • You need the skill Engineering to assemble machines.
  • You can use this to assemble a Blockmaker, a Fuelmaker, a Metal Machine or a Woodworker.
  • This can be purchased from a Hardware Vendor or a Tool Vendor.
