Counter

Plural: Counters

In the remake

In Tiny Speck’s game

Why own a counter? Because it is an admirably flat surface, useful for dividing large spaces. (This is known as 'The Counter Argument'. A Counter-Counter Argument exists, but it only confuses everything).

  • This can be made with a Construction Tool.
  • You need to learn Furnituremaking I to use a Construction Tool.
  • The recipe for this will become available after you learn Furnituremaking II.
